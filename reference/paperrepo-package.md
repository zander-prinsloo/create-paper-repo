# paperrepo: Reproducible project structures for empirical papers

paperrepo creates a Quarto-first workspace for empirical research,
including ordered analysis scripts, dated research notes,
reproducibility metadata, manuscript rendering helpers, and a
journal-ready TeX handoff.

## Lifecycle

paperrepo is under active development. The public API is intentionally
small and may evolve before the first stable CRAN release.
